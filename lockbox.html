Lockbox

A password-protected place for private files.

One encrypted vault on your Mac. Move files in, open them in Finder, and lock the vault when you are done.

Download for Mac ↓

v0.2.8 · Apple silicon · macOS 13+
ZIP · 1.01 MB

Not available for Intel Macs, iPhone, or iPad.

Installation instructions ↓

01 / Getting started

Install on your Mac

  1. Download and open the ZIP file.
  2. Drag Lockbox.app into your Applications folder, then open it.
  3. Choose Create Lockbox, pick a location, and set a password of at least 12 characters.
  4. Use Add Files… to move files or folders into the vault. Allow Finder Automation when prompted if you want closing its window to lock the vault.

macOS may block the first launch

This build is ad-hoc signed and is not notarized by Apple. If you trust this download and macOS blocks it, follow Apple's instructions for opening an app from an unidentified developer. Keep your Mac's security protections enabled.

02 / Everyday use

Open. Add files. Lock.

Unlock with your password to use the files in Finder. Add Files moves the originals into the vault. Files and folders containing symbolic links are rejected.

Choose Lock, quit normally, or close the Finder window Lockbox opened. Lockbox verifies that the volume detached. If a file is still busy, it stays open and shows an error.

While unlocked, files are accessible to other software running as your macOS user. Force quitting or a crash can leave the vault mounted. Reopen Lockbox and lock it normally.

03 / Keep a backup

Keep the password safe.

There is no password reset. Losing the password or the vault can mean losing the files permanently.

Wait for Locked and encrypted, then back up the entire .sparsebundle package to another disk. Test a restored copy with your password before relying on the backup.

Moving files into Lockbox does not erase copies from existing backups, other apps, or previously used disk space.

04 / Release

Version 0.2.8

This release fixes encryption checks while a vault is open. It also includes Finder-window locking fixes, safer file imports, and state checks that keep the interface responsive.
