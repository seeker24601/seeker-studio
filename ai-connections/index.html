03 / Two ways in

Your keys, or theirs.

Your agent picks for you.

direct mode

Your keys most projects

Scripts, servers, bots and tools. Keys come from .env.

npm install ai-connections
full mode

Their keys apps with users

Each user adds their own keys in a settings screen. Keys are stored encrypted on your server.

npx ai-connections-cli init

04 / Safe by default

Safe with other people's keys.

security
  • Keys are encrypted and never sent back.
  • Each key goes only to its own provider.
  • Errors are cleaned before users see them.
  • Only public HTTPS links are fetched.
  • SVG is blocked unless you allow it.
  • Released from public CI, with no stored tokens.
