02 / Why

Every AI project solves the same problems.

Which package talks to which provider. Its base URL, auth header and key variable. How to list its models. Why every SDK throws a different error. How image and video APIs differ: some stream, some return a job to poll, some want references uploaded first. And once users bring their own keys, how to store those safely and give them a settings screen.

AI Connections solves these once, for every provider it knows. Your project, and the agent building it, writes a provider string instead of an integration.

03 / What you get

One way into 42 providers.

  • Text from 30 providers: OpenAI, Anthropic, Google, DeepSeek, Z.ai, Moonshot, Qwen, MiniMax, Mistral, xAI, OpenRouter, Groq, Together, Fireworks, DeepInfra, Cerebras, Hugging Face and more, plus any OpenAI-compatible endpoint.
  • Images and video from 15 providers, including OpenRouter images with live previews and cost, Higgsfield, WaveSpeed, fal and Replicate.
  • Local models done properly: Ollama's own API, so context size and "thinking off" actually apply; LM Studio and vLLM with strict JSON.
  • Model lists straight from each provider, with what each model takes in and costs where the provider says.
  • One error type, with the provider's own message and whether a retry could help.
  • Built on the Vercel AI SDK, so streaming, tools and structured output work as documented.
  • Test helpers with realistic provider replies, so tests cost nothing.

04 / Safe by default

Built for other people's keys.

  • Keys are encrypted at rest, never returned by the API, and sent only to the provider they belong to.
  • Each provider is held to its own address, redirects are refused, and links a provider sends back are fetched only if they are public HTTPS.
  • Raw provider errors, which can echo keys or prompts, never reach end users.
  • Releases are published from GitHub through npm trusted publishing, with no stored tokens.

05 / Status

Open source, in use, honest about limits.

AI Connections runs in Atelier-1111, which reaches 12 image providers through it, and in a multi-agent game harness with 27 text providers and local models.

Providers are checked against their own documentation and tested against local fixtures. Not every one has been tried with a live account, so the first real call to a new provider is the true test, and its error comes back in its own words. AWS Bedrock, Azure and Vertex need dedicated adapters. Requires Node.js 22 or newer.
