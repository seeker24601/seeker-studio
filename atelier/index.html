How it works

  1. 01

    Paste a key

    From any of twelve providers. Atelier tells which one from the key itself.

  2. 02

    Pick a model, write a prompt

    Add reference images to turn a prompt into an edit.

  3. 03

    Keep everything

    Each result is saved on your disk with its prompt, settings and, where the provider reports it, its cost.

Details

Your keys stay with you

Stored on your computer and sent only to their own provider. Atelier answers no one but your machine.

Options that actually work

Each result is checked against what you asked for. Sizes and formats a model refuses or quietly ignores are marked, so you don't pick them again.

Light and dark

Follows your system, or pick one in Settings.

Updates itself

Settings → Updates installs new versions. Every update is signed.

Install on Windows
  1. Run the installer. It installs for you alone and needs no administrator rights.
  2. Open Atelier 1111 and paste a key.

The installer isn't code-signed yet, so SmartScreen may warn you. Choose More info, then Run anyway.

Install on Mac
  1. Open the disk image and drag Atelier 1111 into Applications.
  2. Open it and paste a key.

Needs macOS 13.5 or later. The app isn't notarized by Apple yet. If macOS won't open it, see Apple's guide to opening apps from unidentified developers.

Run from source

On any system with Node.js 22.5 or later:

npm install
npm start

Then open http://127.0.0.1:5180. Details are in the README.
