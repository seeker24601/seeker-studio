# Seeker Studio

Public studio website for seeker-studio.games, hosted on GitHub Pages. Static HTML, CSS and JavaScript with self-hosted fonts and supplied game artwork. No analytics, cookies, external embeds or build dependencies.

Preview with `python3 -m http.server 4330 --bind 127.0.0.1`. Publish from the main branch root through GitHub Pages.

The website repository contains presentation assets only. Seekers of the Deep remains a separate private project. Fonts retain their included SIL Open Font License notices. Artwork and studio content are not licensed for redistribution.
